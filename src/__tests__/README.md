Tests live under src/__tests__ to work with CRA's default Jest discovery.

Useful npm scripts:
- npm run test:list    # show discovered test files
- npm run test:ci      # run tests non-interactively and show each test name with PASS/FAIL
- npm run test:coverage # run tests and print coverage report

To add new tests, place them under src/__tests__/ or name them *.test.{js,jsx} under src/.
